# mediflow_app

Aplicación Android de MediFlow para el Sprint 1, desarrollada con Flutter,
Dart y Material 3. Incluye navegación y selección local de PDF, JPG, JPEG,
PNG y TXT, sin procesamiento ni conexión a servicios.

Consulta [la documentación de Edil](../README.md) para requisitos, ejecución,
estructura y pruebas.
